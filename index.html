YT Uploader

A personal automation tool that uploads and schedules short videos on my own YouTube channel.

What it does: Every day it takes the next videos from a folder on my computer and uploads them to my channel using the official YouTube Data API. It adds each video's title and description and sets a publish time.

Who uses it: Only me, the channel owner. It isn't offered to the public and doesn't access anyone else's account.
